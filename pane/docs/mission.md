# Pane: mission and vision

Pane is a technical platform project; its one user is Jim. The format
follows the product strategy plan (PR 922), so pane reads like the
products do. The roadmap is [roadmap.md](roadmap.md).

## Mission

Pane lets Jim steer all the work in the repo in a few minutes a day. It
shows what needs him and how healthy each part of the repo is, and lets him
act on it, from a laptop or a phone. It only reads the repo and proposes
changes as pull requests, so the repo stays the source of truth and pane
never disagrees with it, or with the README.

## Vision

Jim opens pane and, within a minute, sees two things on one screen: a
short list of every action waiting on him, and one scorecard per domain
(build and deploy, quality, threats, review, infrastructure, requirements,
money, work). On a good day the list is empty and every scorecard is green.
Any scorecard opens down to the projects that make it worse and then to the
evidence, so the detail pane already has (signals, verdicts, money,
reviews) is one click deeper instead of on the first page. Every number on
the dashboard comes from the same files as the README badges and the
audit, so nothing has to be checked twice.
