# Contributing to cloudflare

## Getting Started

### Install Toolchain

Use the Cast install command to install all required dependencies:

```bash
cd pane/cloudflare
cast install
```

### Build

To build the project:

```bash
cargo build
```

### Test

To run Rust unit tests:

```bash
cargo test
```

To run all CI checks (formatting, linting, build, and tests):

```bash
cast ci
```
