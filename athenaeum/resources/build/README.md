# Build

How projects in this repo are built, tested and released. The rules are in
the standards; start there.

- [mise](../../../standards/docs/mise.md): every project's `ci`, `fix`,
  `build`, `test`, `dev`, `release`, `deploy` and `evals` tasks, from the
  shared files in `standards/tasks/`.
- [Git hooks](../../../standards/docs/git-hooks.md): the checks each commit
  and push runs, and what to do in a cloud sandbox.
- "Dev commands" in [AGENTS.md](../../../AGENTS.md): the commands to run.
