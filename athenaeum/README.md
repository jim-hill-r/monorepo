# Athenaeum

This is the knowledge base for information relevant for engineers working in this repo.

Athenaeum means "an institution for the promotion of literary or scientific learning."

## Map

| Folder | Holds |
| --- | --- |
| `learning/` | Study notes, one folder per subject: `computer_science/` (algorithms, API design, databases, operating systems, security, system design), `math/`, `rust/` and `web/`. |
| `resources/` | Reference notes for building things in this repo, one folder per area: `apps/`, `build/`, `games/`, `rust/`, `security/` and `web/`. |
| `issues/` | Open work on the knowledge base, one file per issue. |

How to add a note is in [CONTRIBUTING.md](CONTRIBUTING.md).
