# neet_code_150

A Rust implementation of the [NeetCode 150](https://neetcode.io/) algorithm problems — focused on mastering the top 6 algorithm patterns.

Top 6 algorithms from youtube video:

- HashMaps
- Recursion
- DFS, BFS
  -- Bonus: Most graph algorithms build on this. Learn some graph algorithms
- Binary Search (Hard to identify when to use)
- Sliding Window
- Heaps
  -- Bonus: Minimum spanning tree
