# sparkhill_webapp

A Dioxus web app replicating the functionality of the blue.eel.education website, providing reading instruction and support for learners of all ages.

## About

This application replicates the functionality of the Blue Eel Education website, bringing together resources and information about reading instruction. It covers:

- What We Do: Overview of reading instruction services
- How We Do It: Teaching approaches including Phonological Awareness, Reading Comprehension, Fluency Building, and Vocabulary Development

## Technology

Built with:
- [Dioxus](https://dioxuslabs.com/) - A React-like framework for Rust
- Rust Edition 2024

## Building

To build the application:

```bash
cargo build
```

To run the development server:

```bash
dx serve
```

## Testing

To run Rust unit tests:

```bash
cargo test
```

To run all CI checks (formatting, linting, build, and tests):

```bash
cast ci
```
