Try the three nightly playtest builds of controlled_chaos and file a `fix` issue in `controlled_chaos/issues/` for anything that doesn't run or play right:

- Browser: the `DEPLOY_URL` in `controlled_chaos/mise.toml` (jimhillr-controlled-chaos.pages.dev once the rename is live).
- macOS: [controlled_chaos-macos.zip](https://github.com/jimhillr/monorepo/releases/download/controlled_chaos-nightly/controlled_chaos-macos.zip). It isn't notarized (that needs a paid Apple account), so the first time open System Settings > Privacy & Security and click Open Anyway.
- Android: [controlled_chaos-android.apk](https://github.com/jimhillr/monorepo/releases/download/controlled_chaos-nightly/controlled_chaos-android.apk), the first build with touch controls (#698). Allow your browser to install unknown apps.
