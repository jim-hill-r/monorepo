# The Psy Ents user guide

## Who it's for

The Psy Ents is a children's book for children and the adults who read
with them. Its main characters are psychic tree creatures (ents) who learn
about science on their adventures, and the name is a play on words: "Psy
Ents" sounds like "science".

The stories are written as short rhyming verses to read aloud, one verse
per page, in the style of picture books such as *The Pout-Pout Fish*. No
age has been set for the book yet, so use that as a guide: it is meant for
children who are read to, rather than children reading on their own.

The book is still being written. Today there are two stories, and each has
a title page and the first two lines of its opening verse.

## Getting started

The book lives in the jimhillr monorepo on GitHub and is not published
anywhere else yet, so there is nothing to install or sign in to:

1. Open the [psy_ents folder](https://github.com/jimhillr/monorepo/tree/main/psy_ents)
   in a web browser.
2. Pick a story from the list in its README.
3. Read the story on the page GitHub shows you.

## How to read a story

Each story is its own file, and each `---` line in it starts a new page:

- [The Psy Ents](../../The%20Psy%20Ents.md)
- [The Psy Ents Go Climbing](../../The%20Psy%20Ents%20Go%20Climbing.md)

**Read it on GitHub.** Open the story's file. GitHub shows the whole story
on one long page: a small table at the top (the slide settings, which you
can skip), then the title, then each page separated by a horizontal line.
Read one section between lines at a time, like turning a page.

**Read it as slides.** Each story is also a [Marp](https://marp.app/)
slide deck, so you can show it one page at a time on a screen, which works
well for reading aloud to a group. Open the file in Visual Studio Code with
the free [Marp for VS Code](https://marketplace.visualstudio.com/items?itemName=marp-team.marp-vscode)
extension and open its preview, or, if you have Node.js, download the file
and run `npx @marp-team/marp-cli "The Psy Ents.md" --preview` in the
folder that holds it. Use the arrow keys to turn the pages.

## How to know what age it suits

No age range has been decided for the book. It follows the rhyming
read-aloud picture books it is modelled on, with short verses of about
five to seven syllables a line, so it is best read aloud to young children
by an adult. Because the stories are unfinished, read a story yourself
before reading it to a child.

## Getting help

- **A story stops after two lines.** That is all there is so far: the book
  is still being written.
- **There are numbers at the start of each line, like "5 In a forest".**
  They are the writer's syllable counts for the rhythm. Skip them when you
  read aloud.
- **The story shows as one long page instead of slides.** GitHub doesn't
  show slides. Follow "Read it as slides" above to page through it.
- **The top of the story shows a table with "marp" and "uncover".** Those
  are the slide settings. Skip them; the story starts at the title.

To report a problem, a typo or an idea for a story, tell the person who
shared The Psy Ents with you, saying which story and which page.
