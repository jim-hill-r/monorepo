# Psy Ents

The Psy Ents is a children's book, written as Marp slide decks with one deck
per story. The main characters are psychic tree creatures (ents) who learn
about science on their wild adventures, so the name is a play on words:
"Psy Ents" sounds like "science".

## Writing notes

Pout pout fish is approximately 26 stanzas with each stanza of 4 lines.

The cadence is approximately 5, 5, 7, 7 syllables. Sometimes 5,6,5,5 or 5,6,7,5, but always at least 5.

There is a nice pattern of "blub", "blub", "blub". Try to find a simple thing to include on pages in between the longer stanzas!
