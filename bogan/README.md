# Bogan

[![Eval coverage](https://raw.githubusercontent.com/jimhillr/monorepo/evals-results/badges/bogan.svg)](https://github.com/jimhillr/monorepo/blob/evals-results/verdicts.json)

Bogan is an original online marketplace built around supply-chain
transparency. It is for small sellers and makers, and for the buyers who
want to see where their goods come from: each listing shows who made the
item, where it came from and each hop it took on the way to the buyer.

Bogan has one seller rule that big marketplaces lack: no white-labelled or
copy-cat listings. A seller may not relabel generic goods as their own
brand or list knock-offs of another seller's product. How the rule is
enforced is part of the product brief (`docs/issues/write-product-brief.md`).

Bogan is Algonquin for a quiet tributary or backwater. Bogan brings
transparency to all the tributaries that feed into a big marketplace: we
value the little guys and want consumers to have a real choice.

Bogan is in early design and has no code yet.
