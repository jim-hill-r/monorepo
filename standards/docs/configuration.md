- All projects MUST include a royalty.toml for use with the royalty project. The format (schema 1) is in the [royalty.toml reference](../../royalty/docs/royalty-toml.md); a file with only a `[project]` table with `name` and `description` is valid and means "no payment terms".
- `mise run //:audit` checks it for every project (a directory with a `mise.toml`, not the repo root) through `standards/scripts/royalty-check.sh`: ROY-001 (no royalty.toml), and every finding `royalty check` reports for the file, RTOML-001 onwards (listed in [What `royalty check` reports](../../royalty/docs/royalty-toml.md#what-royalty-check-reports)). They are warnings until every project has a valid file, then they become errors.
