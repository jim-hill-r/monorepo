# Notes on the eval engine's issues

## Evals roadmap

The eval engine's issues are here, under the epic "Evals roadmap", in the
order of the [evals roadmap](../docs/roadmap.md): Phase 1 makes a green
light trustworthy, Phase 2 covers every project, Phase 3 adds real-user
numbers and people's ratings, Phase 4 adds chaos and the agent judge. Work
that belongs to one project (its requirements, smoke tests and production
evals) is in that project's `issues/` with the same epic.

The issues for each requirement that isn't green are written by triage
(`evals triage`) into the requirement's project, not here.
